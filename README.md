# Entomology | علم الحشرات

موقع تعريفي وتعليمي لقسم علم الحشرات.

## تشغيل الموقع
افتح ملف `index.html` في المتصفح.

## النشر على GitHub Pages
1. ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع `entomology`.
2. افتح Settings ثم Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.

## تخصيص الموقع
- عدّل النصوص في `index.html`.
- عدّل الألوان والتنسيقات في `style.css`.
- أضف صور القسم داخل مجلد جديد، ثم اربطها في `index.html`.
